# MyHabits – Habit Tracker 🌱

MyHabits is a simple and responsive habit-tracking web application built using React and TypeScript. It helps users build consistent daily habits, track their progress, and monitor their performance through analytics.

## 🌐 Live Demo

https://myhabits-zeta.vercel.app/

## 📂 GitHub Repository

https://github.com/shubhamkumarr1/myhabits

## ✨ Features

- Add new habits
- Edit existing habits
- Delete habits
- Mark habits as completed or incomplete
- Track current and longest streaks
- Weekly habit calendar
- Date-wise completion history
- Daily analytics and progress tracking
- Weekly progress chart
- Light and Dark theme
- Save data using Browser Local Storage
- Responsive design for desktop, tablet and mobile

## 🛠️ Technologies Used

- React
- TypeScript
- CSS
- Vite
- Browser Local Storage
- Git and GitHub
- Vercel

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/shubhamkumarr1/myhabits.git
```

### 2. Open the project folder

```bash
cd myhabits
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

## 💾 Data Storage

MyHabits uses Browser Local Storage to save habits and user preferences. Data remains available in the same browser after refreshing the page.
